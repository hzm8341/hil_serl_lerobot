1. 项目定位与 CLI 入口

LeRobot 是 HuggingFace 推出的面向真实机器人的 PyTorch 学习框架， 核心能力包括：数据集托管（Hub）、多种 SOTA 策略、真实硬件驱动、仿真环境集成， 以及分布式 RL 与异步推理。目标是用统一接口打通「采集 → 训练 → 部署」全链路。

设计哲学：所有策略继承 PreTrainedPolicy，统一实现 forward(batch)（训练）与 select_action(batch)（推理）； 所有配置通过 draccus 解析 CLI / JSON，支持 Hub 一键加载。

真机推理（control_utils.py → predict_action）

  1. numpy obs → torch tensor，图像转 CHW + [0,1] + batch dim
  2. 注入 task、robot_type 字符串（VLA 策略需要）
  3. policy.select_action(observation)
  4. 返回 cpu numpy/tensor action → robot.send_action()
统一推理接口：所有策略实现 select_action(batch: dict[str, Tensor]) → Tensor。 Action chunking 策略（ACT、Diffusion 等）内部维护 action queue，reset() 在 episode 开始时清空。

干预机制

  • Actor 正常运行 SAC 策略 select_action()
  • 操作者按下 gamepad trigger / 键盘 → action_intervention 覆盖策略动作
  • 键盘路径需先按 i 开启 Intervention ENABLED，方向键 / Shift / Ctrl 才会生效
  • 干预数据同样写入 ReplayBuffer，加速收敛
  • 训练收敛后干预率自然下降

键盘干预键位：i 开关；↑↓←→ 平面移动；左/右 Shift 为 Z-/Z+；左/右 Ctrl 为夹爪闭合/张开。详见 README.md 与 docs/hilserl_sim_notes.html。

本仓库定制：configs/hilserl_sim/ 包含 HIL 仿真配置， envs/configs.py 中 HILEnvConfig 扩展了 timeout、safe_retreat 等安全控制字段。 详见 docs/hilserl_sim_notes.html。

13. Pipeline D：异步远程推理

推理 将策略推理与真机控制解耦，GPU 服务器运行大模型，真机端只做 sensing + actuating。

sequenceDiagram participant RC as Robot Client
(真机) participant GRPC as gRPC participant PS as Policy Server
(GPU) participant P as PreTrainedPolicy RC->>GRPC: SendPolicyInstructions
(加载策略) GRPC->>PS: 加载 from_pretrained PS->>P: make_policy() loop 控制循环 RC->>RC: robot.get_observation() RC->>GRPC: SendObservation GRPC->>PS: 观测队列 (maxsize=1) PS->>P: select_action(obs) P->>PS: action chunk PS->>GRPC: ReturnActions GRPC->>RC: timed actions RC->>RC: robot.send_action() end

支持异步推理的策略：act、diffusion、tdmpc、vqbet、pi0、smolvla
